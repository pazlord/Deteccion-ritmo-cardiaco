
# Track of heart rate, with video

Proyecto hecho para semana TEC, donde se utilizan las variaciones de color verde en la frente, para hacer inferencias sobre el ritmo cardiaco
## Run Locally

Clone the project

```bash
  git clone https://github.com/pazlord/Deteccion-ritmo-cardiaco.git
```

Go to the project directory

```bash
  cd Deteccion-ritmo-cardiaco
```

Install dependencies

```bash
  pip install -r requirements.txt
```

Start the App
```bash
  python main.py
```


## Tech Stack

Python, Open-CV
